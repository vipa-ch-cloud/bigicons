# BigIcons

Виджеты-иконки приложений любого размера для Android. Kotlin, Jetpack Compose, Material 3. Пакет `dev.bigicons.app`, minSdk 26, target/compile SDK 37.

## Возможности

- 12 размеров виджета: 1×1, 1×2, 2×1, 2×2, 2×3, 3×2, 3×3, 4×1, 1×4, 4×2, 4×3, 4×4. Размер можно менять, иконка перерисовывается под реальный размер (`onAppWidgetOptionsChanged`).
- Экран настройки: список приложений с поиском, своя картинка вместо иконки, форма маски, цветовой режим, режим растяжения, подпись, масштаб и отступ, живое превью.
- Рендер в Bitmap: слои adaptive-иконки, маски (в том числе системная `config_icon_mask`), Material You (тематическая иконка), запасной монохромный силуэт для иконок без monochrome-слоя, свой цвет. Своя картинка проходит тот же конвейер маски и цвета.
- Нажатие запускает приложение; если оно удалено, открывается BigIcons.
- Настройки хранятся отдельно для каждого виджета и удаляются в `onDeleted`.
- Перерисовка при установке, обновлении и удалении пакетов, загрузке системы, обновлении BigIcons и смене конфигурации (тема, язык, ориентация).
- Главное приложение с нижней навигацией: «Виджеты» (список, править, сбросить, закрепить виджет нужного размера), «Стиль» (значения по умолчанию), «О приложении».
- Адаптивная иконка самого приложения с monochrome-слоем.

## Режимы

- Форма: авто (системная маска), круг, суперэллипс, скруглённый квадрат, капля, квадрат.
- Цвет: авто (тематический на Android 13+ при наличии monochrome-слоя, иначе оригинал), оригинал, тематический (вариант «Нейтральная» по умолчанию или «Акцент»), свой цвет.
- Растяжение: по центру (одна иконка стандартного размера), растянуть (одна плитка на весь виджет, радиус углов выводится из формы), плитки (сетка иконок по ячейкам).

## Сборка

```
./gradlew assembleRelease     # app/build/outputs/apk/release/app-release.apk
./gradlew test                # юнит-тесты (Layout, Monochrome)
```

Нужны Android SDK (путь в `local.properties`) и JDK 17+. Релиз собирается с R8 (shrink + resources). Подпись: отладочный ключ debug, без собственного keystore. Готовый файл: `dist/BigIcons-1.1.apk`.

Провайдеры, XML и манифест генерирует `tools/gen_widgets.sh` (запуск из корня проекта).

## Выбранные по умолчанию значения

Форма «авто», цвет «авто», режим «по центру», подпись выключена, масштаб 100%, отступ 4%. Сетка оценивается из dp по формуле `ячеек = round((dp + 30) / 70)`. Размер Bitmap ограничен 1 000 000 пикселей (иначе RemoteViews не пройдёт в Binder), при отказе обновления рендер повторяется с меньшим масштабом.

## Ограничения Android

- Лаунчер не сообщает форму своих иконок и сетку. «Авто» берёт системную маску, а не маску лаунчера. Привязки к сетке лаунчера нет, итоговый размер определяет лаунчер.
- Android 12+ может сам скруглять углы виджета.
- `ACTION_CONFIGURATION_CHANGED` нельзя принять из манифеста. Приёмник регистрируется в `Application`, поэтому работает, пока процесс жив. Если процесс остановлен, смена обоев или темы перерисует виджеты только по таймеру `updatePeriodMillis` (30 минут) или при следующем событии.
- Цвета Material You (режим «Тема»): выбор делает чистая функция `ThemeTones.pick`. Тёмная/светлая тема берётся из `uiMode` ресурсов приложения в момент рендера.
  - «Нейтральная» (по умолчанию, как обычные плитки системы): Android 14+ фон `system_surface_container_dark/light`, глиф `system_neutral1_50` (тёмная) / `system_neutral1_900` (светлая); Android 12-13 фон `system_neutral1_900` / `_100`, глиф те же.
  - «Акцент» (как выделенная плитка): Android 14+ фон `system_primary_container_*`, глиф `system_on_primary_container_*`; Android 12-13 фон `system_accent1_800` / `_100`, глиф `system_accent1_100` / `_700`.
  - Ниже Android 12 системных цветов нет, используется запасная фиолетовая палитра.
  - Сами значения подставляет система по выбранному акценту/обоям; на устройстве не сверялись.
- Перерисовка при смене акцента, обоев или темы мгновенной не гарантируется: динамический приёмник `ACTION_CONFIGURATION_CHANGED` работает только пока жив процесс, статического приёмника для этого нет. Надёжные пути: пересчёт при каждом открытии BigIcons, периодическое обновление `updatePeriodMillis` (30 минут, система может его растянуть) и кнопка «Обновить все виджеты» во вкладке «Виджеты».
- Тематический режим приближает Material You цветами системной палитры (`system_accent1_*`, Android 12+), а не использует механизм лаунчера. Монохромный силуэт для иконок без monochrome-слоя эвристический.
- `QUERY_ALL_PACKAGES` нужен для списка приложений; Google Play может запросить обоснование.
- APK подписан отладочным ключом, обновление поверх сборок с другой подписью невозможно.
- Проверено только сборкой, юнит-тестами и `aapt2`/`apksigner`. На устройстве или эмуляторе приложение не запускалось.
